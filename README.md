# Babajide Alao — Portfolio

Interactive portfolio site: live regression playground hero, filterable project cards, career timeline chart, a "Guess the correlation" mini-game, and a hidden terminal (press `` ` ``).

Live: https://babajidealao-knn.github.io

Built with plain HTML, CSS and JavaScript (no build step). Hosted on GitHub Pages.

## Updating
- **Add a project:** edit the `PROJECTS` array at the top of `script.js`.
- **Update experience:** edit the `JOBS` array in `script.js`.
- **New photo / résumé:** replace `profile.jpg` or `Babajide_Alao_Resume.pdf` (keep the same file names).
